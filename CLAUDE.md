# Overview

Create an PWA providing an AI oponent for the tabletop wargame Saganami Island Tactical Simulator. 
The app should allow to create games, setup the ships present (both AI and player controlled) and give orders for the AI ships turn by turn. The player then applies the orders on the physical game table, solves the actions, and report the changes in the app before starting a new turn.

## Game rules

The rules are available in PDF in ./SITS_Core_book.pdf
